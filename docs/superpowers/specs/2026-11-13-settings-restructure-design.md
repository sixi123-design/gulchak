# 설정창 재구성 + 레버 여백 + 이용권 (설계)

날짜: 2026-11-13 · 크기: 작은 변경

## 왜

설정이 복잡해 보인다. 원인은 항목 수(11개)가 아니라 묶음이 안 맞는 것:
"운전석" 탭엔 좌석 높이 하나뿐, "시험장" 탭엔 성격 다른 셋, 레버 글자 토글은
설정이 아니라 HUD 버튼에만 있고, 조작 탭은 대부분 읽기전용 설명이다.
동시에 폰에서 실제로 필요한 설정(레버를 화면 가장자리에서 얼마나 띄울지)이 없다.

## 목표 / 하지 않을 것

- 목표: 탭 5개 → 3개. 찾는 것이 어느 탭에 있는지 바로 보이게.
- 목표: 레버 가장자리 여백 설정 추가 (폰 손 위치·베젤 차이).
- 목표: 이용권을 계정 없이 한 줄로. 구매 복원 자리 확보.
- 하지 않음: 감도·자동 선회 같은 보조 설정. 실기 리얼리티를 깬다.
- 하지 않음: 로그인·회원가입. 1회 과금 앱에 계정은 불필요.
- 실패 조건: 설정이 늘어서 "뭘 만져야 하는지" 더 헷갈려지면 실패.

## 접근 (검토한 세 가지)

- A. 탭 3개로 다시 묶기 — **채택**. 지금 구조에서 옮기기만 하면 되고, 탭 이름이
  곧 "내가 찾는 것"이 된다.
- B. 탭 없애고 한 장 스크롤 — 가장 단순하나 항목이 10개를 넘으면 길어진다.
- C. 기본/고급 2단 — 어느 쪽에 넣을지 매번 애매하고, 고급은 안 열어본다.

## 새 구조

```
설정            [조작] [화면] [시험장]            (확인)
──────────────────────────────────────────────
조작   레버 크기        작게 · 보통 · 크게
       레버 여백        좁게 · 보통 · 넓게      ← 신규
       레버 글자        켜기 · 끄기             ← HUD 버튼에서 이동(동기화)
       진동            켜기 · 끄기             ← 신규
       게임패드         (연결 상태 + 스틱 배치 안내)
       키보드          (키 재지정, 폰에선 숨김)

화면   화질            부드럽게 · 보통 · 선명하게   ← 신규(기본 자동)
       버튼 크기        작게 · 보통 · 크게
       글자 크기        보통 · 크게 · 아주 크게
       좌석 높이        [맞추기 →]  운전석 보며 조절하는 화면으로
       소리            전체 음량(신규) · 엔진 · 환경 · 효과

시험장 내 시험장        (검색 · 가까운 곳)
       굴착기 모델
       시험 시간·계절
       배운 내용 초기화

──────────────────────────────────────────────
이용권 이용 중          [구매 복원]            ← 창 아래 고정 한 줄
```

- 소리는 항목이 4개뿐이라 "화면" 탭 아래에 둔다(탭 하나 줄이는 값이 더 크다).
- 좌석 높이는 탭이 아니라 버튼으로 들어간다. 지금의 `showTab('seat')` ·
  `seatFrom` 되돌리기 로직은 그대로 쓴다.
- 이용권은 탭이 아니라 푸터 한 줄. 계정·로그인 없음.

## 레버 여백

- `styles.css`의 `.stick` 고정값(`max(18px, safe-area)`)을 CSS 변수로:
  `--stick-edge` (기본 18px), `bottom/left/right: max(var(--stick-edge), env(safe-area-inset-*))`.
- 3단계: 좁게 8px · 보통 18px(현행) · 넓게 32px. 기본은 보통이라 기존 화면이 그대로다.
- 저장: `exc-z-edge`. 기존 `UI_SIZES`(`exc-z-*`) 방식에 px 단위 항목으로 합류.

## 진동 · 레버 글자

- 진동: `navigator.vibrate` 호출부가 8곳이라 `buzz(p)` 한 군데로 모으고
  설정이 꺼져 있으면 무시. 저장 `exc-buzz`.
- 레버 글자: HUD 토글(`btn-labels`, `exc-labels`)과 설정이 같은 값을 보게 한다.

## 화질 (신규)

지금은 최저사양 고정이다: `antialias:false`, `dprCap 1.25`, 실시간 그림자 없음(원판으로 흉내),
MeshToon 3단, 후처리 없음. 26fps 밑으로 2초 가면 dpr을 0.75까지 내리지만 다시 올리지는 않는다.

3단으로 둔다. 기본은 자동: 첫 몇 초 프레임을 보고 고른 뒤, 설정에서 사용자가 바꾸면 그 값을 고정한다.

| 단계 | dprCap | 안티에일리어싱 | 먼지·효과 | 그림자 |
|---|---|---|---|---|
| 부드럽게 | 0.75 | 끔 | 적게 | 원판 |
| 보통(현행) | 1.25 | 끔 | 지금 | 원판 |
| 선명하게 | 2.0 | MSAA | 많게 | 햇빛 그림자(2단계) |

- 안티에일리어싱은 컨텍스트 생성 옵션이라 켜고 끄려면 렌더러를 다시 만들어야 한다.
  바꾼 즉시 적용하되 장면 재구성 비용이 크면 "다음 판부터"로 안내한다.
- 자동 하향(`main.ts:2059`)에 자동 상향을 더한다. 단, 사용자가 손으로 고른 뒤에는 자동이 끄진다.
- **흙 격자(`soil.ts`의 cell)는 품질에서 제외한다.** 부피 장부와 합격 판정이 이 격자 위에서
  계산되므로, 화질에 따라 점수가 달라지면 시뮬레이터 신뢰가 깨진다.
- 저장 `exc-q` (`auto` | `0` | `1` | `2`).

### 2단계로 미루는 것: 햇빛 그림자

가장 값진 항목(버킷과 지면의 거리감 = 연습 가치)이지만 `sunLight.castShadow`,
그림자 맵 크기·범위, 받는 면 지정, 가짜 원판 그림자와의 공존 정리까지 필요해
이번 작업과 분리한다. "선명하게"에 나중에 붙인다.

## 전체 음량

지금 `audio.ts`의 master 게인은 0.8 고정이고, 음소거 버튼이 0 / 0.8 로만 바꾼다.
전체 음량 슬라이더가 없어서 "조금만 줄이기"가 안 된다 (개별 3개를 다 내려야 함).

- `Sound.setMaster(v)` 추가: master 게인을 `0.8 * v` 로. 음소거는 지금처럼 0.
- 소리 탭 "전체" 줄에 슬라이더를 넣어 음소거 버튼 옆에 둔다 (다른 3줄과 같은 모양).
- 저장 `exc-vol-all`, 기본 100%.
