# 레버 교실 1단계 다시 만들기 — 대사형 레버 익히기 설계

2026-11-14

## 왜 다시 만드는가

기본기 1단계를 "몸통 돌리고 멈추기"로 만들었다. 실제로 해 보니 두 가지가 틀렸다.

1. **순서가 틀렸다.** 처음 들어온 사람에게 선회(몸통 돌리기)부터 가르쳤다. 이 앱이
   가르치는 것은 흙을 파는 일이고, 그 일은 붐·버킷·암으로 한다. 선회는 운반이다.
2. **레버를 쓸 줄 모르는 사람에게 미션을 줬다.** "왼쪽 레버를 왼쪽으로 밀어 몸통을
   돌리세요"는 지시지, 가르침이 아니다. 레버를 밀면 무엇이 어떻게 움직이는지를
   한 번에 하나씩 보여 주고, 틀리면 그 자리에서 바로잡아야 한다.

그래서 1단계를 **대사형 레버 익히기**로 바꾼다. 한 번에 레버 하나, 지시 → 반응 →
확인 → 다음. 틀리면 그 자리에서 다시.

## 목표

- 레버를 한 번도 안 써 본 사람이, 끝나면 **붐·버킷·암을 각각 어느 레버로 어떻게
  움직이는지** 손으로 안다.
- "무리한 힘을 주면 실격"을 **말로 듣기 전에 몸으로 겪는다** (땅에 박아 보고 배운다).
- 한 레버만 쓰는 것이 기본이라는 것을 안다 (붐이 같이 움직이면 지적받는다).

## 목표가 아닌 것

- 흙을 퍼지 않는다. 담기·운반·붓기는 뒤 미션이다.
- 선회는 다루지 않는다. 지금 1단계였던 "몸통 돌리고 멈추기"는 뒤로 밀린다.
- 합격 여부를 알려주지 않는다.

## 실패로 보는 것

- 글이 길어지는 것. **한 화면에 한 줄**, 짧게. 읽기 싫으면 안 읽는다.
- 모르는 낱말로 시작하는 것. 붐·암·버킷은 **처음 움직일 때 눈앞에서** 이름을 준다.
- 못해서 막히는 것. 틀리면 되돌아가 다시 할 수 있어야 하고, 영원히 못 끝내는 길이
  없어야 한다.
- 장난스러워지는 것. 쓰는 소재는 실제 굴착기에 있는 것뿐이다.

## 화면

### 한 톤 배경

기존 연습장과 **같은 지형·같은 장비**를 쓰고, 색만 뺀다. 지시문과 지금 움직이는
것에 눈이 가게.

- 방법: 캔버스(`#view`)에만 CSS `filter: saturate(...)`. 이 미션 동안만 `<body>`에
  클래스를 붙인다. **새 렌더 패스·새 재질·새 캔버스 없음** — `toon()`의 재질 캐시는
  색마다 하나를 공유하므로 색을 바꾸면 모든 화면이 바뀐다. 그래서 재질을 안 건드린다.
- 캔버스에만 걸므로 레버·글자는 그대로다.
- **저가폰 가드**: 화질이 가장 낮은 단계(`부드럽게`)면 필터를 걸지 않는다. 매 프레임
  전체 화면 합성이 한 번 더 붙는 비용이라, 제일 느린 기기에서는 색보다 프레임이 낫다.
- 부품 강조도 같이 탈색되지만, 강조는 0.22초마다 켜졌다 꺼지는 깜빡임이라 흑백에서도
  보인다.
- 끝나거나 나가면 클래스를 떼서 원래 색으로 돌아온다.

### 배경 지시문

미션 박스(작은 판)가 아니라 **화면 가운데 위쪽에 크게** 띄운다. 두 줄까지:

```
┌─────────────────────────────┐
│                             │
│   오른쪽 레버를 아래로       │   ← 지시 (큰 글자)
│                             │
│         붐이 올라갑니다       │   ← 반응 (작은 글자, 잠깐)
│                             │
│         [3D 굴착기]          │
│                             │
│   ◀ 레버                레버 ▶ │
└─────────────────────────────┘
```

- 지시가 바뀔 때만 다시 그린다. 반응·경고는 잠깐 떴다 사라진다.
- 레버 글자 깜빡임(`.lab.hint`)과 부품 강조(`exc.highlight`)는 이미 있다 — 그대로 쓴다.

## 대사 (순서와 문장)

한 줄씩. **괄호 안은 조건·동작**이고 화면에 안 나온다.

### 1 붐 올리기

```
오른쪽 레버를 아래로              (레버 글자 '붐 올림' 깜빡임 + 붐 강조)
  → (붐이 15° 올라가면)  붐이 올라갑니다
```

### 2 붐 내리기 — 바닥까지

```
오른쪽 레버를 위로 — 바닥에 닿을 때까지
  → (버킷 밑이 흙에 닿으면)   바닥에 닿았습니다
```

"어디서 멈출지" 를 지시문에 넣는다. 안 쓰면 초보는 어디까지 내려야 하는지 모른다.

### 3 눌러 보기 — 왜 실격인지 몸으로

```
닿은 채로 조금 더 눌러 보세요
  → (차체가 들리면)        차체가 들립니다
                           시험에서는 이게 실격입니다
  → (2.5초 지나도 안 들리면) 살살 눌렀네요. 그게 맞습니다
레버에서 손을 떼세요
  → (레버를 놓으면)        장비가 처음 자세로 서서히 돌아온다 (1.2초)
```

**일부러 시킨 일로 벌을 주지 않는다.** 우리가 눌러 보라고 했으므로 "실격입니다"는
꾸중이 아니라 정보로 적는다. 별도 깎지 않는다(아래 등급). 들림 판정은 이미 있는
것을 쓴다 — `s.lift`가 경고 각도(`liftWarnDeg` 2°)의 60%를 넘으면.

살살 눌러 안 들린 사람도 2.5초 뒤 넘어간다. 막히는 길이 없다.

### 4 버킷 펴기

```
오른쪽 레버를 오른쪽으로           ('버킷 펴기' 깜빡임 + 버킷 강조)
  → (버킷이 30° 펴지면)  버킷이 펼쳐집니다
  → (붐이 5° 넘게 같이 움직이면)  붐은 그대로 두세요
  → (붐이 12° 넘게 움직이면)      서서히 처음 자세로 되돌리고 같은 지시를 다시
```

버킷만 움직이는 것이 과제다. 조금 섞이는 것은 봐주고(5° 미만), 보일 만큼 섞이면
알려 주고, 심하면 되돌려 다시 시킨다.

**되돌리기는 `Step.fail`을 쓰지 않는다.** `fail`은 되돌림을 세어 세 번째에 미션
전체를 다시 시작하고(`Tutor.wantReset` → `main.ts`), 자세·흙도 돌아오지 않는다.
이 미션에서는 단계 안에서 자세만 서서히 되돌리고 같은 지시를 다시 보여 준다.

### 5 버킷 오므리기

```
오른쪽 레버를 왼쪽으로
  → 버킷이 오므라듭니다
  (붐 섞임 같은 기준)
```

### 6 암 당기기

```
왼쪽 레버를 아래로                ('암 당기기' 깜빡임 + 암 강조)
  → 암이 접힙니다 — 버킷이 몸 쪽으로 옵니다
  (붐 섞임 같은 기준)
```

### 7 암 펴기

```
왼쪽 레버를 위로
  → 암이 펴집니다 — 버킷이 멀어집니다
```

### 8 중간에서 멈추기

```
붐을 올리다가 중간에서 멈춰 보세요
  → (붐이 10° 이상 올라간 뒤 레버를 놓고 붐이 서면)  레버를 놓으면 멈춥니다
```

방향만 익히고 끝내면 "조작을 배웠다"는 느낌이 안 든다. 놓으면 멈춘다는 것을 한 번
확인하고 끝낸다. 정확히 멈추는 연습은 다음 미션들이 한다.

### 9 마무리

```
이 셋으로 흙을 팝니다
  붐으로 높이 · 버킷으로 각도 · 암으로 거리
```

마지막 줄은 끝낸 뒤 클리어 화면의 한 줄 평으로도 쓴다.

## 이론 카드

미션 앞 한 장. 왜 이걸 하는지부터.

```
왜 레버부터 하나

굴착기는 레버 두 개로 움직입니다.
흙을 파는 데는 셋을 씁니다 —
  붐(높이) · 버킷(각도) · 암(거리).
하나씩 눌러 보고 무엇이 움직이는지 보세요.
```

## 판정과 등급

이 미션은 **익히는 자리**다. 끝까지 오면 **별 3개**다. 깎지 않는다.

- 땅을 눌러 본 것은 우리가 시킨 일이다. 그걸로 깎으면 벌이 된다.
- 붐이 섞여 되돌아간 것도 배우는 과정이다.
- 끝낸 뒤 한 줄: "붐으로 높이 · 버킷으로 각도 · 암으로 거리"

점수는 다음 미션들이 매긴다. 첫 미션에서 등급으로 겁을 주면 두 번째를 안 한다.

## 서서히 복귀

"레버에서 손을 떼세요" 다음, 그리고 각 단계를 다시 시작할 때, 장비가 **1.2초에
걸쳐 처음 자세로 돌아온다**. 순간이동(`teleport`)은 무슨 일이 일어났는지 안 보인다.

- 매 프레임 목표 자세로 조금씩 옮기되 **`teleport()`를 쓴다**. `setPose`는 자세만
  바꾸고 관절 속도와 흙 경로 기준값을 그대로 둬서, 복귀하는 동안 지나간 자리를
  흙 깎기로 셀 수 있다(`session.ts` 흙 장부). `teleport`는 매번 속도를 0으로 하고
  경로 기준을 다시 잡는다.
- 복귀 중에는 레버 입력을 무시한다.
- 화면 프레임 수에 따라 시간이 조금 달라지는 것은 연출이라 괜찮다.

## 기존 것은 어떻게 되나

- 지금 1단계 "몸통 돌리고 멈추기"는 **새 1단계 뒤로** 밀린다 (2단계가 됨).
  내용은 그대로 둔다 — 운반할 때 필요한 기술이다.
- 그 뒤 "버킷 높이 맞춰 멈추기 → 버킷 곧게 옮기기 → 흘리지 않고 곧게 멈추기"는
  순서만 한 칸씩 밀린다.
- 기존 배우기 7개(기초·숙련)는 손대지 않는다.

기본기 다섯 개가 된다:
`레버 익히기 → 몸통 돌리고 멈추기 → 버킷 높이 맞춰 멈추기 → 버킷 곧게 옮기기 →
흘리지 않고 곧게 멈추기`

## 엔진에 더할 것

지금 `Lesson`/`Step`에 둘만 더한다.

```ts
// Step: 지시문을 배경에 크게 띄울 것인가 (미션 박스 대신)
big?: boolean;
// Step: 지시 아래에 잠깐 띄울 반응·경고 (이미 있는 hud를 쓴다)
```

복귀와 한 톤 배경은 `Lesson` 수준의 스위치로 둔다.

```ts
flat?: boolean;   // 한 톤 배경
home?: boolean;   // 되돌아갈 때 서서히 복귀
```

## 빌더에게 남기는 것

- `saturate()` 값. 흙과 장비가 구분되는 최소한으로.
- 각 단계의 각도 문턱(15°·30°·5°·12°)의 최종 조정. 위 값은 출발점이다.
- 배경 지시문의 글자 크기·위치 (휴대폰 가로에서 장비를 가리지 않게).
- 복귀 1.2초의 최종 조정.
