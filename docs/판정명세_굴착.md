# 굴착작업 판정 명세 (연습모드 v1)

- 규칙 버전: `2026.11-qnet2022-r1`
- 공식 근거: 큐넷 공개문제 굴착기운전기능사(2022년도)의 실격 사유 Q1~Q15 (원문은 큐넷 공개문제 자료실 참고)
- 표기
  - **[공식]**: 공개문제에 적힌 조건
  - **[해석]**: 공개문제에 수치나 방법이 없어서 이 앱이 정한 구현 조건. 설정값(`src/config/rules.json`)으로 바꿀 수 있습니다.

---

## 1. 좌표계와 시험장

- 단위는 m, 각도는 rad입니다. y축이 위쪽이고, 장비 선회 중심이 원점입니다.
- 선회각 ψ의 버킷 방향은 (cos ψ, 0, sin ψ)입니다. **A = ψ π (−x 방향), B = ψ π/2 (+z 방향), C = ψ 0 (+x 방향)**입니다. A에서 B를 지나 C로 가는 것이 왼쪽 선회(ψ 감소)입니다.
- 각 지점(A·C)의 국소 좌표: 반경 ρ = p·축, 측면 λ = p.z. B는 +z 쪽에 있습니다.

### 1-1. 장비 치수에서 계산하는 값 [공식 정의, 계산은 해석]
| 기호 | 정의 | 계산 |
|---|---|---|
| reach (ⓐ) | 붐·암·버킷을 최대로 뻗었을 때 최대 도달거리 | 암을 최대로 펴고 버킷을 일직선(φk=0)으로 둔 상태에서 버킷 끝이 지면(y=0)에 닿는 붐 각도를 찾고, 그때의 반경 |
| β | 붐을 최대로 세우고 암을 최대로 오므렸을 때 암 끝 핀의 높이 | 정기구학 |
| βr | β 자세에서 암 끝 핀의 반경 (β지점) | 정기구학 |

### 1-2. A·C 지점 [공식]
| 요소 | 반경 ρ | 측면 λ | 높이 |
|---|---|---|---|
| ⓑ선 (줄) | reach − 0.30 | ±(W/2 + 0.5) | 0.5 |
| 구덩이 | [ⓑ − 0.30 − 2.5·Lb, ⓑ − 0.30] | ±W/2 | — |
| ⓒ선 (줄, 굴착구역선) | [구덩이 안쪽 끝 − 0.50, ⓑ] | ±(W/2 + 0.5) | 0.5 |
| 가상굴착제한선 (줄 없음) | 구덩이 안쪽 끝 − 0.50 | ±(W/2 + 0.5) | — |
| ⓓ 오버스윙제한선 (줄) | [ⓒ 안쪽 끝, reach] | −(W/2 + 0.5 + 0.2) (B 반대편) | β − 0.5 |
| 폴 | ⓑ·ⓒ 모서리 4개는 높이 0.5, ⓓ 양 끝 2개는 높이 β | | |

- W는 버킷 가로 폭, Lb는 버킷 세로 폭입니다.
- [해석] 구덩이 초기 상태
  - A: 흙 표면이 −0.5(기준면), 단단한 바닥이 −1.6입니다.
  - C: 빈 구덩이이며 바닥이 −0.5입니다.
  - 구덩이 밖 지면은 0이고 깎을 수 없습니다.

### 1-3. B지점 [공식]
| 요소 | 위치 |
|---|---|
| ⓔ 폴 | +z 방향, 반경 βr + 0.5, 높이 β |
| ⓕ 폴 | +z 방향, 반경 reach − 1.0, 높이 β |
| 장애물선 (줄) | ⓔ와 ⓕ 사이, 높이 β − 1.0 |
| 가상통과제한선 | ⓔ·ⓕ 위치에서 위로 뻗은 수직선 |
| 버킷 통과구역 | 반경 (rE, rF) 사이이고 장애물선보다 위. **[해석] 위쪽 한계는 두지 않습니다** (`passTopLimit: null`) |

## 2. 판정 대상 형상 [해석]

모든 형상은 고정 시간 간격(60Hz)마다 갱신합니다. 렌더링 프레임과는 무관합니다.

| 부위 | 형상 | 반경(두께) |
|---|---|---|
| 붐 | 선분 P0→P1 | 0.22 |
| 암 | 선분 P1→P2 | 0.16 |
| 버킷 | 꼭짓점 6개(핀·힐·끝 × 좌우 ±W/2)를 잇는 모서리 선분 8개 | 0.05 |
| 폴 | 수직 선분 (지면 → 높이 h) | 0.03 |
| 줄 | 선분 | 0.015 |

- **접촉**: 두 선분 사이 최단거리 < 두 반경의 합. 3D 선분-선분 거리로 계산합니다.
- **연속 경로 검사**: 한 스텝 사이 이동량이 판정 반경보다 크면 스텝을 나눠 검사합니다. 빠른 선회 중에 줄을 빠져나가 놓치는 일을 막기 위해서입니다.

## 3. 실격 이벤트

| ID | 근거 | 이벤트 조건 |
|---|---|---|
| D-POLE (폴·줄) | Q11 [공식] | 붐·암·버킷 형상이 어떤 폴이나 줄에 **접촉** |
| D-POLE (오버스윙) | Q11 [공식] | 암 끝 핀이나 버킷 꼭짓점이 어느 지점의 ρ ∈ [ⓒ 안쪽 끝 − 0.5, reach + 0.5] 범위에서 λ < ⓓ선 측면 위치로 넘어감 (높이 무관) **[해석]** |
| D-DIGLINE | Q12 [공식] | 버킷 꼭짓점이 **작업 높이(y < 0.5) [해석]**에 있으면서 지점 주변 띠(구역 ±1.0) 안, 굴착구역 직사각형 밖에 있음. 줄이 없는 가상굴착제한선 쪽도 포함 |
| D-PASS | Q13 [공식] | 버킷 꼭짓점이 B 평면(x = 0)을 가로지르는 순간 다음 중 하나: ① 반경이 (rE + 0.05, rF − 0.05) 밖 (버킷 두께만큼 **제한선 접촉도 위반**), ② 높이가 장애물선 + 0.05 이하, ③ −z 쪽(B 반대편)으로 가로지름 = B 통과구역을 지나지 않음 |
| D-COUNT | Q14 [공식] | 종료 시점에 유효 굴착 횟수(4장) < 4 |
| D-NOFLAT | Q15 [공식] | 종료 시점에 평탄작업 수행(4장) 조건 미충족 |
| D-TIME | Q1 [공식] | 작업 시간이 240초를 넘음 |
| D-STALL | Q10 [공식] | 엔진 정지. **[해석]** rpm < 0.35인 상태에서 굴착 부하(초당 깎는 양 > 0.03 m³ 또는 바닥에 막힘)가 0.8초 이상 이어지면 정지 |

- 같은 ID와 같은 세부 대상(예: "A-ⓑ선")은 1.5초 안에 다시 기록하지 않습니다.
- 연습모드는 실격 이벤트를 기록하고 "실전이었다면 실격"으로 표시하되, 작업은 계속합니다.
- **그만하기 버튼은 기권(중도 종료)**입니다. 정상 종료는 4장의 종료 조건으로만 일어나며, 기권하면 D-COUNT·D-NOFLAT 검사를 하지 않고 결과에 "중도 종료"로 표시합니다.
- **흙 장부**에는 버킷 적재량, 떨어지는 입자, 쏟기 대기량, 흘린 양을 모두 포함합니다. 테스트에서는 매 스텝 float32 누적 오차 1e-5 이하를 요구합니다.

### 자체 경고 (실격 아님)
| ID | 조건 |
|---|---|
| W-DANGER | 버킷 꼭짓점이 흙 표면보다 0.05 이상 아래에 있는 상태에서 선회 속도 > 3°/s |
| W-IMPACT | 버킷이 단단한 바닥이나 지면에 하강 속도 > 0.4 m/s로 부딪힘 ("쾅") |

## 4. 작업 이벤트 [해석]

- **흙 장부**: 구덩이 높이 변화량 + 버킷 적재량 + 떨어지는 중인 흙 + 구역 밖으로 흘린 흙 = 0. 매 스텝 성립해야 하며 테스트로 검증합니다.
- **유효 굴착 1회**
  1. 버킷 중심이 A 영역(선회각이 A축 ±30° 이내, ρ가 구역 ±0.5 이내)에서 흙을 0.2·평적 이상 퍼 담습니다.
  2. 이어서 버킷 적재량이 0.3·평적 이상인 상태로 A 영역을 벗어납니다.
  3. 이때 적재량/평적 비율을 흙량 지표로 기록합니다.
- **덤프 1회**
  - C 영역에서 버킷이 0.2·평적 이상을 쏟은 뒤, 다음 중 하나가 일어나면 1회로 셉니다: ① 적재량이 0.1·평적 미만, ② 버킷 끝이 C 영역을 벗어남, ③ 다음 굴착을 시작함
  - 쏟은 위치와 C 이탈 여부는 모두 **버킷 끝** 기준으로 판단합니다.
  - 굴착 1회당 덤프는 최대 1회입니다. 나눠 쏟아도 여러 번 세지 않습니다.
- **평탄작업 수행**: 첫 덤프 이후 C 격자 안에서 버킷이 흙을 밀어낸 양(퍼 담지 않고 민 부피)의 합이 0.03 m³ 이상
- **작업 종료**
  1. 버킷 상대각이 최대 펼침 각도 − 8° 이상이고,
  2. 버킷의 가장 낮은 점이 흙 표면이나 지면에서 **±0.06 이내**이며 (흙에 묻힌 상태는 인정하지 않음),
  3. 모든 관절 속도가 2°/s 미만인 상태가 1.0초 이어지면 종료합니다.
  4. 종료 시점에 D-COUNT와 D-NOFLAT을 검사합니다.

## 5. 자체 연습 지표 (공식 아님, 결과 화면에 "추정·연습 지표"로 표시)
| 지표 | 정의 |
|---|---|
| 흙량 | 유효 굴착마다 적재량 ÷ 평적 용량 (1.0 = 평적) |
| 굴착 위치 | 각 굴착에서 처음 흙을 깎은 순간, 버킷 끝 중심과 목표점(ρ = ⓑ − 0.30, λ = 0) 사이의 수평 거리 |
| 연결동작 | 조작 중인 시간 가운데 2개 이상의 관절을 동시에 움직인 시간의 비율 |
| 평탄도 | C 구덩이 칸 기준: ① 목표면(0)과의 평균 편차, ② 표준편차, ③ 최고점 − 최저점, ④ C 구덩이 밖에 남은 흙 부피 |
| 시작 전 점검 | 작업 시작 시 안전벨트 체결, 안전레버 해제, rpm ≥ 0.6 여부 |
| 바닥 충격 | W-IMPACT 횟수 |

## 6. 아트 디렉션 (아케이드 스타일)
- 굵은 외곽선(3D는 뒷면 외곽선, UI는 3px 잉크색 테두리)과 3단 툰 셰이딩을 씁니다.
- 고채도 팔레트를 씁니다: 장비 노랑 #FFC23A, 잉크 #1D1B2E, 흙 #9A5B2E, 위험 #FF4D5E, 성공 #2FD27A, 하늘 #7FD3FF.
- 버튼은 눌림 그림자가 있는 스티커형이고, 글자는 큰 굵은 숫자를 씁니다.
- 실격·성공 연출은 짧고 경쾌하게 합니다: 흔들림, 도장 찍기, 배지.
- 실시간 그림자 없이 버킷 아래에 그림자 원을 깔아 높이를 가늠할 수 있게 합니다.
- 실존 게임의 캐릭터, 로고, 화면 구성은 사용하지 않습니다.
