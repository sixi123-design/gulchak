# 굴착작업 판정 명세 (연습모드 v1)

- 규칙 버전: `2026.11-qnet2022-r1`
- 공식 근거: 큐넷 공개문제 굴착기운전기능사(2022년도)의 실격 사유 Q1~Q15 (원문은 큐넷 공개문제 자료실 참고)
- 표기
  - **[공식]**: 공개문제에 적힌 조건
  - **[해석]**: 공개문제에 수치나 방법이 없어서 이 앱이 정한 구현 조건. 설정값(`src/config/rules.json`)으로 바꿀 수 있습니다.

## 1. 좌표계와 시험장

- 단위는 m, 각도는 rad입니다. y축이 위쪽이고, 장비 선회 중심이 원점입니다.
- 선회각 ψ의 버킷 방향은 (cos ψ, 0, sin ψ)입니다. **A = ψ π (−x 방향), B = ψ π/2 (+z 방향), C = ψ 0 (+x 방향)**입니다. A에서 B를 지나 C로 가는 것이 왼쪽 선회(ψ 감소)입니다.
- 각 지점(A·C)의 국소 좌표: 반경 ρ = p·축, 측면 λ = p.z. B는 +z 쪽에 있습니다.

### 1-1. 장비 치수에서 계산하는 값 [공식 정의, 계산은 해석]
| 기호 | 정의 | 계산 |
|---|---|---|
| reach (ⓐ) | 붐·암·버킷을 최대로 뻗었을 때 최대 도달거리 | 암을 최대로 펴고 버킷을 일직선(φk=0)으로 둔 상태에서 버킷 끝이 지면(y=0)에 닿는 붐 각도를 찾고, 그때의 반경 |
| β | 붐을 최대로 세우고 암을 최대로 오므렸을 때 암 끝 핀의 높이 | 정기구학 |
| βr | β 자세에서 암 끝 핀의 반경 (β지점) | 정기구학 |

### 1-2. A·C 지점 [공식]
| 요소 | 반경 ρ | 측면 λ | 높이 |
|---|---|---|---|
| ⓑ선 (줄) | reach − 0.30 | ±(W/2 + 0.5) | 0.5 |
| 구덩이 | [ⓑ − 0.30 − 2.5·Lb, ⓑ − 0.30] | ±W/2 | — |
| ⓒ선 (줄, 굴착구역선) | [구덩이 안쪽 끝 − 0.50, ⓑ] | ±(W/2 + 0.5) | 0.5 |
| 가상굴착제한선 (줄 없음) | 구덩이 안쪽 끝 − 0.50 | ±(W/2 + 0.5) | — |
| ⓓ 오버스윙제한선 (줄) | [ⓒ 안쪽 끝, reach] | −(W/2 + 0.5 + 0.2) (B 반대편) | β − 0.5 |
| 폴 | ⓑ·ⓒ 모서리 4개는 높이 0.5, ⓓ 양 끝 2개는 높이 β | | |

- W는 버킷 가로 폭, Lb는 버킷 세로 폭입니다.
- [해석] 구덩이 초기 상태
  - A: 흙 표면이 −0.5(기준면), 단단한 바닥이 −1.6입니다.
  - C: 빈 구덩이이며 바닥이 −0.5입니다.
  - 굴착장 격자(굴착구역선 밖 1.2m까지)의 지면은 높이 0의 **흙**이며 −1.2m까지 깎입니다. 실제 시험장처럼 구덩이 둘레도 같이 파이지만, 선을 넘거나 건드리면 실격입니다(D-DIGLINE·D-POLE). 격자 밖은 단단한 바닥입니다.
  - 장비는 시험장 주력 14톤급 휠 굴착기 치수(버킷 폭 1.05m, 세로 폭 1.0m, 고봉 약 0.58㎥, 도달거리 약 7.9m)를 씁니다. 구덩이와 선은 이 값으로 자동 계산합니다.

### 1-3. B지점 [공식]
| 요소 | 위치 |
|---|---|
| ⓔ 폴 | +z 방향, 반경 βr + 0.5, 높이 β |
| ⓕ 폴 | +z 방향, 반경 reach − 1.0, 높이 β |
| 장애물선 (줄) | ⓔ와 ⓕ 사이, 높이 β − 1.0 |
| 가상통과제한선 | ⓔ·ⓕ 위치에서 위로 뻗은 수직선 |
| 버킷 통과구역 | 반경 (rE, rF) 사이이고 장애물선보다 위. **[해석] 위쪽 한계는 두지 않습니다** (`passTopLimit: null`) |

## 2. 판정 대상 형상 [해석]

모든 형상은 고정 시간 간격(60Hz)마다 갱신합니다. 렌더링 프레임과는 무관합니다.

| 부위 | 형상 | 반경(두께) |
|---|---|---|
| 붐 | 선분 P0→P1 | 0.22 |
| 암 | 선분 P1→P2 | 0.16 |
| 버킷 | 꼭짓점 6개(핀·힐·끝 × 좌우 ±W/2)를 잇는 모서리 선분 8개 | 0.05 |
| 폴 | 수직 선분 (지면 → 높이 h) | 0.03 |
| 줄 | 선분 | 0.015 |

- **접촉**: 두 선분 사이 최단거리 < 두 반경의 합. 3D 선분-선분 거리로 계산합니다.
- **연속 경로 검사**: 한 스텝 사이 이동량이 판정 반경보다 크면 스텝을 나눠 검사합니다. 빠른 선회 중에 줄을 빠져나가 놓치는 일을 막기 위해서입니다.

## 3. 실격 이벤트

| ID | 근거 | 이벤트 조건 |
|---|---|---|
| D-POLE (폴·줄) | Q11 [공식] | 붐·암·버킷 형상이 어떤 폴이나 줄에 **접촉** |
| D-POLE (오버스윙) | Q11 [공식] | 암 끝 핀이나 버킷 꼭짓점이 어느 지점의 ρ ∈ [ⓒ 안쪽 끝 − 0.5, reach + 0.5] 범위에서 λ < ⓓ선 측면 위치로 넘어감 (높이 무관) **[해석]** |
| D-DIGLINE | Q12 [공식] | 버킷 꼭짓점이 **작업 높이(y < 0.5) [해석]**에 있으면서 지점 주변 띠(구역 ±1.0) 안, 굴착구역 직사각형 밖에 있음. 줄이 없는 가상굴착제한선 쪽도 포함 |
| D-PASS | Q13 [공식] | 버킷 꼭짓점이 B 평면(x = 0)을 가로지르는 순간 다음 중 하나: ① 반경이 (rE + 0.05, rF − 0.05) 밖 (버킷 두께만큼 **제한선 접촉도 위반**), ② 높이가 장애물선 + 0.05 이하, ③ −z 쪽(B 반대편)으로 가로지름 = B 통과구역을 지나지 않음 |
| D-COUNT | Q14 [공식] | 종료 시점에 유효 굴착 횟수(4장) < 4 |
| D-NOFLAT | Q15 [공식] | 종료 시점에 평탄작업 수행(4장) 조건 미충족 |
| D-TIME | Q1 [공식] | 작업 시간이 240초를 넘음 |
| D-STALL | Q10 [공식] | 엔진 정지. **[해석]** rpm < 0.35인 상태에서 과부하 누적량(5-2)이 0.15를 넘으면 정지 |

- 같은 ID와 같은 세부 대상(예: "A-ⓑ선")은 1.5초 안에 다시 기록하지 않습니다.
- 연습모드는 실격 이벤트를 기록하고 "실전이었다면 실격"으로 표시하되, 작업은 계속합니다.
- **그만하기 버튼은 기권(중도 종료)**입니다. 정상 종료는 4장의 종료 조건으로만 일어나며, 기권하면 D-COUNT·D-NOFLAT 검사를 하지 않고 결과에 "중도 종료"로 표시합니다.
- **흙 장부**에는 버킷 적재량, 떨어지는 입자, 쏟기 대기량, 흘린 양을 모두 포함합니다. 테스트에서는 매 스텝 float32 누적 오차 1e-5 이하를 요구합니다.

### 자체 경고 (실격 아님)
| ID | 조건 |
|---|---|
| W-DANGER | 버킷 꼭짓점이 흙 표면보다 0.05 이상 아래에 있는 상태에서 선회 속도 > 3°/s |
| W-IMPACT | 버킷이 단단한 바닥이나 지면에 하강 속도 > 0.4 m/s로 부딪힘 ("쾅") |
| W-JOLT | 급정지·급반전·실린더 끝 충돌로 장비가 덜컹거림 (5-1 참고) |
| W-OVERLOAD | 무리한 굴착으로 엔진 과부하 (5-2) |
| W-LIFT | 버킷으로 땅을 눌러 차체가 들림 (5-2) |
| W-NEAR | 작업 높이(0.6m 미만)의 버킷 꼭짓점이 굴착구역 안에서 선(ⓑ·ⓒ·가상굴착제한선)까지 15cm 이내 — 실격 전에 미리 알려주는 교육용 경고 |

## 4. 작업 이벤트 [해석]

- **흙 장부**: 구덩이 높이 변화량 + 버킷 적재량 + 떨어지는 중인 흙 + 구역 밖으로 흘린 흙 = 0. 매 스텝 성립해야 하며 테스트로 검증합니다.
- **유효 굴착 1회**
  1. 버킷 중심이 A 영역(선회각이 A축 ±30° 이내, ρ가 구역 ±0.5 이내)에서 흙을 0.2·평적 이상 퍼 담습니다.
  2. 이어서 버킷 적재량이 0.3·평적 이상인 상태로 A 영역을 벗어납니다.
  3. 이때 적재량/평적 비율을 흙량 지표로 기록합니다.
- **덤프 1회**
  - C 영역에서 버킷이 0.2·평적 이상을 쏟은 뒤, 다음 중 하나가 일어나면 1회로 셉니다: ① 적재량이 0.1·평적 미만, ② 버킷 끝이 C 영역을 벗어남, ③ 다음 굴착을 시작함
  - 쏟은 위치와 C 이탈 여부는 모두 **버킷 끝** 기준으로 판단합니다.
  - 굴착 1회당 덤프는 최대 1회입니다. 나눠 쏟아도 여러 번 세지 않습니다.
- **평탄작업 수행**: 첫 덤프 이후 C 격자 안에서 버킷이 흙을 밀어낸 양(퍼 담지 않고 민 부피)의 합이 0.03 m³ 이상
- **작업 종료**
  1. 버킷 상대각이 최대 펼침 각도 − 5° 이상이고 (최대한 펼침),
  2. 버킷 바닥 가운데가 **C 구덩이(메우고 평탄한 흙) 위**에 있고 — 마지막 평탄 동작에 이어 그 자리에 내려놓음,
  3. 버킷의 가장 낮은 점이 흙 표면에서 +0.06 ~ −0.25 이내이며 (깊이 묻힌 상태는 불인정),
  4. 모든 관절 속도가 2°/s 미만인 상태가 1.0초 이어지면 종료합니다.
  5. 종료 시점에 D-COUNT와 D-NOFLAT을 검사합니다.

## 5. 자체 연습 지표 (공식 아님, 결과 화면에 "추정·연습 지표"로 표시)
| 지표 | 정의 |
|---|---|
| 흙량 | 유효 굴착마다 적재량 ÷ 평적 용량 (1.0 = 평적) |
| 굴착 위치 | 각 굴착에서 처음 흙을 깎은 순간, 버킷 날 중심과 목표점(ρ = ⓑ − 0.30, λ = 0)의 **앞뒤(dr)·좌우(dl) 오차**. 둘 중 큰 값이 10cm 이내면 좋음, 20cm 이내면 보통. 연습모드에서는 즉시 알려주고 구덩이 위에 목표 띠(±10cm)를 표시 |
| 연결동작 | 조작 중인 시간 가운데 2개 이상의 관절을 동시에 움직인 시간의 비율 |
| 평탄도 | C 구덩이 칸 기준: ① 목표면(0)과의 평균 편차, ② 표준편차, ③ 최고점 − 최저점, ④ C 구덩이 밖에 남은 흙 부피 |
| 시작 전 점검 | 작업 시작 시 안전벨트 체결, 안전레버 해제, rpm ≥ 0.6 여부 |
| 바닥 충격 | W-IMPACT 횟수 |

## 5-0. 모드 [자체]
| | 자유 연습 | 시험 연습 | 실제 시험 |
|---|---|---|---|
| 시간 | 제한 없음(경과 시간 표시) | 4분, 넘어도 계속(D-TIME 기록) | 4분, 넘으면 실격 종료 |
| 실격 | 알림만 | 알림 후 계속 | 즉시 종료 |
| 단계 안내 | 없음 | 있음 | 없음 |
| 경고·위치 피드백·바닥 목표선 | 있음 | 있음 | 없음 |
| 종료 | 그만하기 | 버킷 내려놓기 | 버킷 내려놓기 (그만하기 = 기권) |

- 배우기(무료): 스테이지 6개 — 레버 익히기 · 퍼 담기 · B 통과 선회 · 흙 쏟기 · 평탄 · 마무리. 각 스테이지는 그 구간 자세에서 바로 시작하고, 단계별 지시와 쓸 레버 라벨을 반짝여 줍니다. 미션 정의: `src/sim/tutorial.ts`, 테스트: `tests/tutorial.test.ts`.
- 이용권: 자유 연습(·배우기)은 무료, 시험 연습·실제 시험은 유료(🔒). 결제 연동 전이라 `src/core/entitlement.ts`가 기기 저장소 표시로만 판단합니다(테스트: 주소에 `?pro=1`/`?pro=0`).
- 설정에서 시험장을 검색해 고르면 그 시험장 작업용 장비 계열(현대/두산/볼보 색 조합)로 바뀝니다. 목록: `src/config/sites.json` (큐넷 「시험장별 소재지 및 기종 현황」 26.09.07. 엑셀, 작업용 장비 있는 76곳). 장비 이름은 글자로만 표시하고 로고·사진은 쓰지 않습니다.
- 안전벨트·안전레버·RPM 점검은 연습 범위에서 뺐습니다. 시작하면 벨트 체결, 레버 해제, RPM 80%인 상태입니다.

## 5-1. 유압 조작감 [해석·자체]
| 항목 | 내용 |
|---|---|
| 레버 감도 | 입력 = 기울기^2.2, **선회는 기울기^3**. 조금 기울이면 아주 천천히 움직여 미세 조작이 쉬움 (선회: 레버 30% ≈ 1°/s, 50% ≈ 4°/s, 끝까지 ≈ 35°/s) |
| 유압 응답 | 레버를 밀면 시간상수 0.25초(선회는 상부 차체가 무거워 0.4초)로 서서히 붙고, 놓으면 0.09초로 빠르게 멈춤 (밸브가 닫힘) |
| 실린더 쿠션 | 관절 한계 6° 앞부터(최소 25% 속도) 저절로 감속해 부드럽게 멈춥니다(실제 실린더 끝 쿠션). 이 감속은 충격으로 세지 않으므로, 버킷을 끝까지 오므리는 정상 조작은 덜컹하지 않습니다 |
| 덜컹(충격) | 감속도가 최대속도의 3.5배/초를 넘거나, 실린더 끝(스트로크 엔드)에 30% 이상 속도로 닿으면 충격. 붐을 길게 뻗을수록, 흙을 많이 실을수록 커짐 |
| 충격 결과 | 차체 흔들림(약 1.6Hz 감쇠 진동, 화면에서는 2배로 과장), 카메라 떨림, 폰 진동, 경고 W-JOLT. 고봉(평적 초과)으로 실은 흙은 큰 충격에 쏟아짐 |
| 보정 기준 | 최대 속도에서 레버를 즉시 놓으면 경고, 0.5초 이상 서서히 놓으면 경고 없음 (테스트로 고정) |
| 키보드 | 입력을 초당 4씩 올리고 내림 (갑자기 떼면 약하게 덜컹) |

## 5-2. 퍼 담기·굴착 저항 [해석·자체]
| 항목 | 내용 |
|---|---|
| 담기 | 흙은 **버킷 날(맨 앞줄)**로만 들어갑니다. 담기는 비율 = (날의 이동 방향과 개구부 법선의 일치도: 45°보다 크면 0, 18° 이내면 1) × (0.35 + 0.65 × 오므림 정도)입니다. 오므림 정도는 버킷 상대각이 최대 속도의 25% 이상으로 줄어들면 1입니다. 오므리지 않고 아래로 찌르기만 하면 0입니다. 수직으로 꽂으면 옆으로 밀리기만 하고, **비스듬히 꽂은 뒤 당기며 오므려야** 가득 찹니다 |
| 버킷 속 흙 분포 | 담긴 흙은 먼저 입구 쪽(앞)에 쌓입니다. 오므리면(초당 3배) 또는 입구가 위를 향하면(무게) 안쪽(바닥, 평적의 85%)으로 밀려 들어갑니다. 입구 쪽 흙은 입구가 충분히 위를 향하지 않으면 흘러내립니다. 굴착마다 '끝까지 담김' 비율을 기록합니다 |
| 끝까지 오므리기 | 시험에서처럼 퍼 담은 뒤 버킷을 끝까지 오므린 채 선회하는 것이 기본입니다. 흙을 담고 덜 오므린 채 운반하면 안내하고, 운반 중(A·C 영역 밖) 흘린 흙을 연습 지표로 보여줍니다 |
| 이빨 | 날 끝에서 날 방향으로 12cm 튀어나온 이빨 5개가 먼저 파고들어, 지나간 자리에 골이 남습니다 |
| 평탄 요령 | 평탄 중 버킷을 끝까지(최대 펼침 −25° 이내) 펴고 이빨로 앞으로 민 비율을 연습 지표로 보여줍니다 |
| 다져진 흙 | 원래 지면과 버킷이 깎아낸 면은 `firm`(다져진 흙)입니다. 깎을 수는 있지만 흘러내리지 않습니다. 쏟거나 밀어낸 흙만 안식각으로 무너집니다 |
| 굴착 저항 | 다져진 흙은 1, 흐트러진 흙은 0.05로 셉니다. 날 끝은 0.3 + 2 × (날 방향과 이동 방향의 어긋남)을 곱합니다. 힐이 앞장서면 어긋남은 1입니다. 몸통 줄이 다져진 흙을 깎으면 1.5를 곱합니다(날이 가른 길을 따라가지 못하는 나쁜 각도라는 뜻). 단단한 바닥을 미는 레버 입력도 저항에 더합니다 |
| 엔진 부하 | 부하 = 저항 ÷ 엔진 힘(0.165 + 0.33 × rpm)입니다. 부하가 1을 넘으면 유압 릴리프로 동작이 느려집니다. 화면 하단에 부하 게이지가 있습니다 |
| 과부하·엔진 정지 | ∫max(0, 부하 − 1)dt를 1.5초에 걸쳐 감쇠시킨 누적량이 0.08을 넘으면 W-OVERLOAD입니다. rpm < 0.35인 상태에서 누적량이 0.15를 넘으면 엔진이 정지합니다(D-STALL, Q10) |
| 차체 들림 | 누적량 × 아래로 누르는 비율에 비례해 버킷 쪽 차체가 들립니다(최대 5°). 2°를 넘으면 W-LIFT입니다 |
| 바닥 관통 | 단단한 바닥 아래로 **더 깊어지는** 관절 동작만 막습니다. 버킷 하부 점마다 따로 비교하므로, 느리게 조금씩 뚫는 동작도 막힙니다. 바닥에 닿은 채 오므리거나 드는 동작은 허용합니다 |
| 과부하 유지 | 과부하로 유압이 막힌 상태에서 레버를 계속 밀면 부하가 유지됩니다 |
| 첫 삽 위치 | 버킷 **날**이 A지점 흙을 처음 깎은 위치입니다 |
| 제한사항 | 깎아낸 면(다져진 흙)은 흘러내리지 않아, 깊게 판 벽이 수직으로 남을 수 있습니다. 덤프 구덩이 벽을 지키기 위한 선택입니다 |
| 보정 기준 (테스트로 고정) | 바른 퍼 담기(얕게 물고 당기며 오므림): 경고 없이 평적 이상. 깊게 욕심내 물기·등으로 벽 밀기·뒤로 젖혀 찍기: 과부하. 붐으로 땅 누르기: 들림. 낮은 rpm으로 파기: 엔진 정지 |


## 5-3. 소리 [자체]
| 소리 | 조건 |
|---|---|
| 엔진 | rpm에 따라 높낮이·크기가 바뀌고, 부하(5-2)·릴리프가 걸리면 낮게 깔림 |
| 유압 흐름 | 관절이 움직이는 만큼 |
| 릴리프 밸브 | 실린더 끝(한계 0.5° 이내)에 닿은 채 그쪽으로 레버를 계속 밀 때 고음. **끝까지 오므렸는지 소리로 알 수 있음** |
| 흙 쏟아짐 | 버킷에서 흙이 빠져나가는 양(m³/s)에 비례하는 '쏴아' |
| 흙 떨어짐 | 땅에 떨어지는 양에 비례하는 낮은 '우르르'. 조금씩 흘릴 때는 '투둑' 하는 짧은 소리 |
| 덜컹 | W-JOLT·W-IMPACT |
| 호각 | 작업 시작(길게 1번), 실전이었다면 실격(짧게 2번) |
- 화면: 떨어지는 흙은 크기와 색이 다른 덩어리가 회전하며 떨어지고, 떨어진 자리에 먼지가 피었다 사라집니다.
- 오디오 파일 없이 Web Audio로 합성합니다. 휴대폰은 '준비 완료'를 누를 때 소리가 켜집니다. 🔊 버튼으로 음소거할 수 있습니다.

## 6. 아트 디렉션 (아케이드 스타일)
- 굵은 외곽선(3D는 뒷면 외곽선, UI는 3px 잉크색 테두리)과 3단 툰 셰이딩을 씁니다.
- 고채도 팔레트를 씁니다: 장비 노랑 #FFC23A, 잉크 #1D1B2E, 흙 #9A5B2E, 위험 #FF4D5E, 성공 #2FD27A, 하늘 #7FD3FF.
- 버튼은 눌림 그림자가 있는 스티커형이고, 글자는 큰 굵은 숫자를 씁니다.
- 실격·성공 연출은 짧고 경쾌하게 합니다: 흔들림, 도장 찍기, 배지.
- 실시간 그림자 없이 버킷 아래에 그림자 원을 깔아 높이를 가늠할 수 있게 합니다.
- 실존 게임의 캐릭터, 로고, 화면 구성은 사용하지 않습니다.
