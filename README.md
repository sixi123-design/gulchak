# 굴착 연습장 (굴착기운전기능사 실기 연습 · 굴착작업)

큐넷 공개문제(굴착기운전기능사 2022년도) 기준으로 굴착작업을 연습하는 웹 앱입니다. 저가 폰에서도 돌아가도록 가볍게 만들었습니다.

## 실행
```bash
npm install
npm run dev        # http://localhost:5173 (같은 와이파이의 폰에서도 접속 가능: --host)
npm test           # 판정·흙·작업 한 바퀴 테스트
npm run build      # dist/ 정적 파일 (Capacitor로 앱 포장 가능)
```
- `?debug`를 붙이면 fps, 시뮬레이션 시간, 드로우콜, 흙 장부 오차가 표시됩니다.

## 조작
| 레버 | 위·아래 | 좌·우 |
|---|---|---|
| 왼쪽 (W A S D) | 암 펴기 / 암 당기기 | 선회 |
| 오른쪽 (I J K L, 방향키) | 붐 내림 / 붐 올림 | 버킷 오므림 / 펴기 |

- 레버 배치는 ISO 방식입니다. 시험장 장비에 따라 다를 수 있습니다.
- 안전레버를 풀어야 레버가 움직입니다.
- rpm이 낮은 상태에서 무리하게 파면 엔진이 꺼집니다.

## 구조
```
src/config/   machine.ts(가상 장비 사양), rules.json(규칙·판정 파라미터, 버전·출처 포함)
src/core/     ruleEngine.ts   순수 규칙 엔진 (연습/시험 플래그)
src/sim/      kinematics(정·역기구학) site(공개문제 도면 공식으로 시험장 생성)
              soil(높이맵·안식각) judge(폴·줄·구역·B통과 기하 판정) session(60Hz 고정 스텝 상태 머신)
src/render/   Three.js 툰 렌더링 (외곽선, 흙 메시, 입자, 그림자 원)
src/ui/       가상 레버, 키보드, 아케이드 스타일 CSS
docs/         판정명세_굴착.md (구현 기준)
tests/        단위 테스트 + 자동 조작으로 굴착 4회→덤프→평탄→종료 한 바퀴 검증
```

## 원칙
- 판정은 공개문제 실격 사유(Q1~Q15)만 "실격"으로 처리합니다. 수치가 공개되지 않은 부분은 `[해석]` 파라미터로 분리했습니다.
- 점수·합격 여부는 판정하지 않습니다. 공식 점수 산식이 없기 때문입니다. 결과 화면의 지표는 "연습 지표(추정)"로 표시합니다.
- 장비 사양은 가상값이고, 시험장은 공개문제의 도면 공식으로 생성합니다. 다른 앱의 코드·에셋·수치는 쓰지 않습니다.
- 이 앱은 한국산업인력공단과 관련이 없는 비공식 연습 도구입니다.
